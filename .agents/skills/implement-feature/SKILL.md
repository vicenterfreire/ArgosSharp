# ArgosSharp Feature Implementation

1. Read the task and shared project instructions.
2. Inspect the existing implementation and tests.
3. Identify acceptance criteria and affected architecture layers.
4. Present a plan before multi-file changes.
5. Implement the smallest coherent change.
6. Add or update relevant tests.
7. Run build and tests.
8. Review the final diff.
9. Report unresolved issues and verification results.

Do not expand scope without approval.
